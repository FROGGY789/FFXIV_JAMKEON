# 전멸 연구소

우리 부대 절(Ultimate) 트라이용 기믹 노트 + 트라이 일지.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 전멸 연구소 메인 (레이드 목록, 기믹, 트라이 일지). `support.js`, `image-slot.js` 런타임 필요 |
| `uwu-note.html` | 절테마 기믹 노트 (단독 페이지) |
| `uwu-data.js` | 절테마 기믹 데이터 + 평면도 그리기 (`window.UWU`) |
| `arena3d.js` | 기믹 도식 3D 뷰어 |
| `docs/design-reference.png` | 디자인 참고 이미지 |

## 3D 뷰어

평면도 아래 **3D로 보기** 버튼을 누르면 같은 기믹을 입체로 볼 수 있어요.

- 드래그로 회전, 휠·핀치로 확대, 우클릭·두 손가락으로 이동
- 시점: 위에서 / 쿼터뷰 / 낮게
- 롤 시점: T1~D4 버튼(또는 말 클릭) → 그 롤 뒤에서 보기 + 강조
- 표시 토글: 장판 / 롤·보스 / 화살표·줄 / 글자, 자동 회전

평면도 데이터(`d: [...]`)를 그대로 읽기 때문에 기믹을 추가하면 3D도 자동으로 생겨요.
`draw()`가 만드는 `<svg data-arena="N">`을 찾아서 버튼을 붙이는 방식이라, 다른 절 노트도
같은 `draw()` 형식을 쓰고 `arena3d.js`만 불러오면 돼요.

three.js(0.160.0)는 처음 3D를 열 때 jsdelivr CDN에서 불러와요.

### 데이터 형식 (요약)

좌표는 `at:[각도, 거리]`(북=0°, 시계방향, 필드 반지름 100) 또는 `xy:[x, y]`.

| 항목 | 예 |
|---|---|
| 원형 장판 | `{z:'c', at:[90,30], r:11, k:'bad'}` (`k`: bad / safe / buf) |
| 도넛 | `{z:'donut', at:[0,0], r1:42, r2:100}` |
| 부채꼴 | `{z:'cone', at:[0,0], dir:90, w:150, len:96}` |
| 직선 장판 | `{z:'band', a:pol(0,100), b:pol(180,100), w:44}` |
| 롤 | `pp('T1', 330, 26)` / `px('T1', x, y)` |
| 보스·오브젝트 | `{b:'가루다', at:[0,0], r:11}` |
| 화살표 / 원호 화살표 | `{ar:[[x1,y1],[x2,y2]], dash:1}` / `{arc:{r, a1, a2}}` |
| 줄(테더) | `{te:[pol(270,84), pol(270,66)]}` |
| 글자 / 필드 마커 | `{t:'징표', at:[90,95]}` / `{m:'A', at:[0,80]}` |
