## 상세 규칙

### 1. 데스롤 (Deathroll)
- **인원:** 2명 이상 (보통 1:1)
- **방법:** 첫 사람이 `/random 999` → 나온 숫자 N으로 다음 사람이 `/random N` → … **1이 나온 사람이 패배**.
- **팁:** 판돈(길)을 거는 게 원조지만, 벌칙(이모트, 다음 던전 탱커 하기 등)으로 해도 충분히 재밌음.

### 2. 주사위 카지노
- **인원:** 딜러 1명 + 플레이어 2~8명
- **방법:** 북미 하우징 "카지노 벤뉴" 문화. `/random`·`/dice`로 블랙잭, 하이로우(High/Low), 룰렛 흉내를 냄.
- **주의:** 현금 거래(RMT)와 엮이면 약관 위반. 게임 내 길드·벌칙으로만.

### 3. 빙고
- **인원:** 사회자 1 + 다수
- **방법:** 참가자는 외부 빙고판 생성 사이트로 판을 받고, 사회자가 `/random 75`로 번호를 부름.

### 4. OX 퀴즈
- **인원:** 사회자 1 + 5~50명
- **방법:** 하우징 마당이나 필드에 O 구역 / X 구역을 정함. 문제 낸 뒤 카운트다운 → 틀린 쪽 탈락.
- **팁:** 파판 스토리·NPC 대사·아이템 문제로 내면 고인물 vs 뉴비 대결이 됨.

### 5. 퀴즈쇼
- **인원:** 사회자 1 + 다수 (개인전/팀전)
- **방법:** 채팅으로 먼저 정답 치는 사람 득점. "이 BGM 어디서 나옴?", "이 몹 이름은?", "이 장소 스샷 맞히기" 등.

### 6. 숨바꼭질
- **인원:** 술래 1~2 + 4~30명
- **방법:** 범위(예: 하우징 한 블록, 특정 마을)를 정하고 숨기. 제한 시간 안에 술래가 찾으면 `/target` 후 이모트로 "찾았다".
- **규칙 예시:** 미니언 소환 금지, 투명 마운트 금지, 실내 진입 가능/불가 명시.

### 7. 술래잡기
- **인원:** 술래 1 + 4~20명
- **방법:** 좁은 맵에서 술래가 쫓아가 근접 이모트(`/poke`)를 걸면 술래 교대.
- **참고:** 파판은 캐릭터끼리 충돌판정이 없어서 "몸으로 막기"는 안 됨.

### 8. 무궁화 꽃이 피었습니다
- **인원:** 술래 1 + 5~30명
- **방법:** 술래가 등을 돌리고 채팅으로 "무궁화 꽃이…", "피었습니다!"를 치면서 뒤돌아봄. 그때 움직이는 사람 탈락.
- **팁:** 채팅 지연이 있어서 술래가 약간 관대하게 판정하는 게 좋음.

### 9. 의자 뺏기
- **인원:** 사회자 1 + 5~20명
- **방법:** 하우징에 의자 가구를 (인원-1)개 배치. 바드가 연주하다 멈추면 앉기(`/sit`). 못 앉은 사람 탈락, 의자 하나씩 제거.

### 10. 점프 퍼즐
- **인원:** 1명~ (같이 하면 서로 놀리는 맛)
- **유명 코스:** 쿠가네 탑 오르기, 각종 맵 숨겨진 지붕/고지대, 유저 제작 하우징 점프맵.
- **팁:** "누가 먼저 꼭대기에서 `/sit` 하나" 레이스로 하면 좋음.

### 11. 미로 / 탈출 하우스
- **인원:** 1명~
- **방법:** 하우징 가구로 미로·방탈출·장애물 코스를 만들어 공개. 일본에서 "アスレチックハウス"로 크게 유행.

### 12. 마피아 / 늑대인간
- **인원:** 사회자 1 + 6~15명
- **방법:** 사회자가 귓속말(`/tell`)로 직업(마피아/시민/의사/경찰 등) 배정. 하우징 원탁에서 낮 토론·투표, 밤에는 사회자에게 귓말로 행동.

### 13. 달리기·탈것 레이스
- **인원:** 2~30명
- **방법:** 시작·결승 지점을 정하고 레이스. 변형 규칙: "달리기 금지, 걷기만", "같은 탈것 통일", "비행 금지".

### 14. 운동회
- **인원:** 2팀, 팀당 4~24명
- **방법:** 위 게임들(레이스, OX, 무궁화, 점프)을 종목으로 묶어 팀 점수제. FC 이벤트로 인기.

### 15. 글래머(패션) 콘테스트
- **인원:** 심사위원 1~3 + 참가자 다수
- **방법:** 주제(예: "여름 휴가", "악역", "초코보 테마")를 미리 공지. 런웨이를 걷고 심사·투표.

### 16. 그포 촬영회 / 플래시몹
- **인원:** 4명~수십 명
- **방법:** 드레스 코드를 맞추고 단체 사진(그룹 포즈). 또는 같은 춤 이모트를 동시에 써서 도시 한복판에서 플래시몹.

### 17. 바드 합주 공연
- **인원:** 연주 1~8명(파티 합주 기능) + 관객
- **방법:** 음유시인 연주 기능으로 합주. 해외에서는 하우징 "클럽 벤뉴"에서 바드 공연이 하나의 문화.

### 18. 낚시 대회
- **인원:** 2명~ (오션 피싱은 최대 24명)
- **방법:** 제한 시간 안에 가장 큰/희귀한 물고기 잡기. 오션 피싱을 같이 타고 점수 대결도 가능.

### 19. 보물지도 파티
- **인원:** 8명 (풀파티)
- **방법:** 각자 지도 하나씩 가져와 돌아가며 파기. 보물고 포털 뜨면 다 같이 진입 → 문 선택 운빨 게임이 핵심 재미.

### 20. 제한 플레이
- **인원:** 4 / 8 / 24명 (콘텐츠에 따라)
- **예시:** 걷기만, 1인칭 시점, UI 숨기기, 알몸, 같은 직업만 8명, 청마도사 파티, 최소 아이템 레벨, 블라인드, 힐러 없이 클리어.
- 👉 **[상세 정리 + 제한 룰렛 보기](docs/restriction-play.md)**

### 21. 하우징 투어
- **인원:** 2명~
- **방법:** FC원·친구 집을 돌면서 구경하고 "베스트 하우징" 투표.

### 22. PvP 내전
- **인원:** 10명 (5 vs 5)
- **방법:** 크리스탈라인 컨플릭트 사용자 지정 매치로 팀을 나눠 내전. 승패 걸고 하면 진심이 됨.

## 공통 주의사항
- **서드파티 툴(플러그인) 사용은 약관 위반**입니다. 잼컨은 기본 기능(`/random`, `/dice`, 이모트, 하우징)만으로 진행하세요.
- 판돈을 걸 경우 게임 내 길드만, **현금 거래는 절대 금지**.
- 필드에서 대규모로 모일 땐 다른 유저 통행·사냥 방해가 되지 않게 장소를 고르세요.
