# 전멸 연구소

우리 부대 절(Ultimate) 트라이용 기믹 노트 + 트라이 일지.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 전멸 연구소 메인 (레이드 목록, 기믹, 트라이 일지). `support.js`, `image-slot.js` 런타임 필요 |
| `uwu-note.html` | 절테마 기믹 노트 (단독 페이지) |
| `uwu-data.js` | 절테마 기믹 데이터 + 평면도 그리기 (`window.UWU`) |
| `arena3d.js` | 기믹 도식 3D 뷰어 |
| `admin.js` | 관리자 로그인 + 사진 업로드 |
| `docs/design-reference.png` | 디자인 참고 이미지 |

## 관리자 (사진 올리기)

사이트 오른쪽 아래 **관리자** 버튼 → 비밀번호로 로그인.

처음 한 번만 설정 필요 (로그인 창의 "처음 설정 / 비밀번호 변경"):

1. GitHub → Settings → Developer settings → [Fine-grained tokens](https://github.com/settings/personal-access-tokens/new)
2. Repository access: `FROGGY789/survival_diary`만 선택, Permissions: **Contents · Read and write**
3. 토큰 + 새 비밀번호 입력 → 토큰이 비밀번호로 암호화돼서 `gh-pages`의 `admin-key.json`에 저장됨

로그인하면 레이드 카드의 사진 칸에 이미지를 끌어다 놓거나 클릭해서 올릴 수 있음.
사진은 `gh-pages` 브랜치의 `.image-slots.state.json`에 바로 커밋되고, 다른 사람 화면에는 1~2분 뒤 반영됨.
`admin-key.json`은 공개 파일이라 비밀번호가 짧으면 뚫릴 수 있음. 길게 쓸 것.

> 사이트는 `gh-pages` 브랜치에서 배포됨. 관리자가 올린 사진 커밋도 거기 쌓이니까, 코드 수정을 올릴 때는
> `gh-pages`를 먼저 받아서(merge) 올려야 사진이 안 날아감.

## 3D 뷰어

평면도 아래 **3D로 보기** 버튼을 누르면 같은 기믹을 입체로 볼 수 있어요.

- 드래그로 회전, 휠·핀치로 확대, 우클릭·두 손가락으로 이동
- 시점: 위에서 / 쿼터뷰 / 낮게
- 롤 시점: T1~D4 버튼(또는 말 클릭) → 그 롤 뒤에서 보기 + 강조
- 표시 토글: 장판 / 롤·보스 / 화살표·줄 / 글자, 자동 회전
- **재생**: ① 배치 → ② 장판 → ③ 이동 순서로 애니메이션. 단계 번호를 눌러 그 단계만 다시 볼 수 있어요.
- **공략 순서**: 오른쪽 위 버튼으로 카드의 공략 문구를 3D 화면 옆에 펼쳐 봐요.

### 재생 순서

- 기본(자동): 화살표의 시작점·끝점 근처에 있는 롤이 그 화살표를 따라 움직여요.
  실선 화살표가 먼저(이동 ①), 점선 화살표가 나중(이동 ②)이에요.
- 직접 쓰기: 카드의 `d` 배열에 `seq`를 넣으면 그 순서대로 움직여요.
  `mv`에 적은 롤만 이동하고, 나머지는 제자리예요. 좌표는 `[x, y]` 또는 `pol(각도, 거리)`.

```js
{seq:[
  {s:'전원 장판 밖에 모여 바람의 칼날 2회'},
  {s:'D1 먼저 장판에 들어가 정화', mv:{D1:[-40,-8]}},
  {s:'D1은 밖으로, 힐러가 피 채우기', mv:{D1:[-6,-8]}},
  {s:'D2 정화', mv:{D2:[-40,12]}}
]}
```

평면도(`draw()`)는 `seq`를 무시하니까 2D 도식에는 영향이 없어요. 예시는 가루다 "바람의 칼날 2회" 카드에 있어요.

평면도 데이터(`d: [...]`)를 그대로 읽기 때문에 기믹을 추가하면 3D도 자동으로 생겨요.
`draw()`가 만드는 `<svg data-arena="N">`을 찾아서 버튼을 붙이는 방식이라, 다른 절 노트도
같은 `draw()` 형식을 쓰고 `arena3d.js`만 불러오면 돼요.

three.js(0.160.0)는 처음 3D를 열 때 jsdelivr CDN에서 불러와요.

### 데이터 형식 (요약)

좌표는 `at:[각도, 거리]`(북=0°, 시계방향, 필드 반지름 100) 또는 `xy:[x, y]`.

| 항목 | 예 |
|---|---|
| 원형 장판 | `{z:'c', at:[90,30], r:11, k:'bad'}` (`k`: bad / safe / buf) |
| 도넛 | `{z:'donut', at:[0,0], r1:42, r2:100}` |
| 부채꼴 | `{z:'cone', at:[0,0], dir:90, w:150, len:96}` |
| 직선 장판 | `{z:'band', a:pol(0,100), b:pol(180,100), w:44}` |
| 롤 | `pp('T1', 330, 26)` / `px('T1', x, y)` |
| 보스·오브젝트 | `{b:'가루다', at:[0,0], r:11}` |
| 화살표 / 원호 화살표 | `{ar:[[x1,y1],[x2,y2]], dash:1}` / `{arc:{r, a1, a2}}` |
| 줄(테더) | `{te:[pol(270,84), pol(270,66)]}` |
| 글자 / 필드 마커 | `{t:'징표', at:[90,95]}` / `{m:'A', at:[0,80]}` |
