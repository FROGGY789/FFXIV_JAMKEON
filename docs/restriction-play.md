# 제한 플레이 (縛りプレイ / Challenge Run) 상세

평소에 하던 던전·토벌전을 **스스로 규칙을 걸고** 다시 깨는 놀이입니다.
일본에서는 「縛りプレイ」, 북미·유럽에서는 "Challenge Run" / "Self-imposed rules"라고 부릅니다.

> 📌 **확인 범위:** 「✅ 실제 기록」은 기사로 확인한 사례입니다. 「🎲 잼컨용 룰」은 커뮤니티에서 이야기로 돌아다니거나 친구끼리 하기 좋은 규칙이고, 기록이 남은 공식 사례를 찾지는 못했습니다(걷기만, 1인칭 등). 출처는 맨 아래에 있습니다.

## 2. 이동 제한

### 🎲 걷기만 하기 (걷기 縛り)
- **방법:** `/walk` (또는 걷기 전환 키)로 걷기 모드 켜고 끝까지 유지. 실수로 풀리면 벌칙.
- **인원:** 4인 던전, 8인 토벌전 둘 다 가능
- **포인트:** 장판 피하기가 늦어져서 **장판 시전 시작 즉시 움직이는 습관**이 생김. 넉백·돌진 스킬(엔·이동기)은 허용할지 미리 정하기.
- **추천 콘텐츠:** 낮은 레벨 토벌전(이프리트, 타이탄 등)부터 → 익숙해지면 레벨 동기화 던전.
- **변형:** 걷기 + 스프린트 허용 / 걷기 + 탈것 금지 / "보스 HP 50% 아래부터만 걷기".

### 🎲 스프린트·탈것 금지
- 던전 이동 구간이 길어져서 레이스 같은 맛은 없지만, **"몹 몰이를 어떻게 하느냐"** 가 달라짐. 입문용 제한.

### 🎲 점프 금지 / 계속 점프
- 점프 금지는 거의 영향이 없고, **"이동할 땐 무조건 점프하면서"** 가 시각적으로 웃김. 영상 찍기용.

## 3. 시야 제한

### 🎲 1인칭 시점으로 살아남기
- **방법:** 마우스 휠로 끝까지 줌인하면 1인칭 시점이 됨. 전투 끝날 때까지 줌아웃 금지.
- **인원:** 4/8명 (전원 1인칭 or 한 명만 1인칭 벌칙)
- **포인트:**
  - 내 발밑 장판이 거의 안 보여서 **바닥 보면서 고개 돌리기**가 핵심.
  - 보스 뒤로 가는 기믹, 산개 위치, 탑 밟기 같은 게 지옥.
  - 탱커가 1인칭이면 보스 방향 잡기가 진짜 어려움 → 제일 웃긴 포지션.
- **변형:** "죽은 사람은 1인칭" 벌칙 룰, "한 명만 몰래 1인칭" 마피아식 룰.
- **주의:** 멀미 나는 사람은 쉬어가기. VR 모드 같은 외부 툴은 약관 위반 가능성이 있으니 쓰지 말 것.

### 🎲 UI 숨기기
- **방법:** UI 숨기기 단축키(기본 Scroll Lock)로 HUD 전부 끄고 전투.
- **포인트:** HP바·시전바·파티 리스트·버프가 다 안 보임. 힐러는 **모션과 감으로** 힐해야 함. 토벌전 하나 깨면 엄청 뿌듯함.
- **변형:** 힐러만 UI 숨기기, 파티 리스트만 끄기(HUD 레이아웃에서 개별로 숨기기).

### 🎲 카메라 고정 / 최대 줌인
- 1인칭보다 순한 맛. "카메라 거리 최소 + 회전 금지" 정도로 하면 입문용.

## 4. 장비 제한

### 🎲 알몸 (무기만 착용)
- **방법:** 무기 외 방어구·악세 전부 해제. 무기를 빼면 스킬을 못 쓰니 무기는 남김.
- **포인트:** 레벨 동기화 던전에선 의외로 버팀. 탱커가 알몸이면 체감이 큼.
- **잼컨 팁:** 글래머로 다 같이 속옷 통일 → 단체 스크린샷.

### 최소 아이템 레벨 (Minimum IL) + 초월하는 힘 해제
- **방법:** 임무 찾기 설정에서 "최소 아이템 레벨"과 "초월하는 힘(에코) 해제"를 켜고 매칭. 출시 당시 스펙으로 싸우는 느낌.
- **인원:** 4/8/24명 (공식 기능이라 아무 콘텐츠나 가능)
- **포인트:** 공식 기능이라 규칙 판정이 필요 없음. 대신 매칭되는 모르는 사람에게 피해 안 가게 **고정 파티로** 갈 것.

### 아이언맨 (거래·장터 금지, 내가 만든 것만)
- **방법:** 장비·소모품을 전부 직접 채집·제작한 것만 사용. 장터·거래 금지.
- **인원:** 1명~ (보통 개인 장기 챌린지)
- 잼컨보다는 **FC 장기 이벤트**용. 한 달 동안 아이언맨으로 키우고 마지막에 같이 토벌전.

## 5. 파티 조합 제한

### ✅ 힐러 없이 / 탱커 없이
- **실제 기록:** 최고 난이도인 절(Ultimate) 레이드에서 힐러 없는 클리어, 탱커 없는 클리어가 해외에서 화제가 됐음. 절 오메가 검증전(TOP)·절 미래 재생전(FRU) 힐러 없는 클리어 보도가 있고, 2026년 6월에는 캐스터+힐러만으로 칠흑 절 클리어 보도도 있음.
- **잼컨으로 하려면:** 레벨 동기화 일반 던전/토벌전에서 시도. 힐러 없으면 **포션·자힐 스킬 관리**, 탱커 없으면 **어글 핑퐁**이 재미 포인트.

### ✅ 힐러만 (HO 런)
- **실제 기록:** 해외 유저가 새 캐릭터로 시작해서 그룹 콘텐츠는 힐러만 참가하는 "HO Run"을 진행.
- **잼컨으로 하려면:** 4인 던전에 힐러 4명. 화력이 낮아서 딜 체크가 관건. 힐러끼리 "누가 딜 제일 많이 넣나" 경쟁하면 재밌음.

### 🎲 같은 직업 8명
- **방법:** 8명 모두 같은 직업(예: 전원 기공사, 전원 무도가, 전원 용기사).
- 같은 직업 제한은 고정 파티(파티 모집 → 인원 제한 없음 설정)로 가야 함.
- **잼컨 포인트:** 똑같은 글래머까지 맞추면 그림이 웃김. 전원 용기사로 점프 연출은 국룰.

### 🎲 청마도사만
- 청마도사는 임무 찾기 매칭이 안 돼서 **직접 파티 짜서 가야 함**. 청마도사끼리 옛날 토벌전 가는 "청마 파티"는 해외에서 흔함.

## 6. 인원 제한

### 🎲 인원 미달
- **방법:** 임무 찾기 "인원 미달 허용"으로 2~3명이서 8인 토벌전.
- **추천:** 레벨 높은 캐릭터로 옛날 극 토벌전 → 기믹 처리하는 맛이 남음.

### ✅ 솔로 전용
- **실제 기록:** RathGames라는 해외 유저가 파티를 아예 안 짜는 "솔로 전용" 챌린지로 메인 스토리를 진행 중. 레이드 보스 하나를 혼자 잡는 데 85일이 걸렸다는 인터뷰가 있음. 동맹 레이드처럼 혼자 못 들어가는 콘텐츠는 같은 챌린지 하는 사람들끼리 모여서 해결함.
- **실제 기록:** 일본에서도 「워리어 오브 라이트 토벌전」을 혼자 깬 플레이어가 화제가 됨 (2026년 6월 보도).
- 잼컨보다는 **개인 도전**. FC에서 "솔로로 어디까지 가나" 기록 대결용.

## 7. 스킬 제한

### ✅ 기본 공격만
- **실제 기록:** 해외 유튜버가 기본 공격 위주로 전투를 제한한 채 신생 메인 스토리를 약 15시간에 클리어 (스프린트·텔레포·귀환·리밋 브레이크는 허용).
- **잼컨 버전:** "콤보 1번 스킬만", "버튼 3개만" 등. 단축바를 비워두고 시작하면 판정이 쉬움.

### 🎲 생존기·경감기 금지
- 탱커 무적기 금지, 파티 경감 금지 등. 힐러가 고생하는 룰이라 **힐러에게 보상** 주기.

## 8. 소통 제한

### 🎲 채팅·보이스 금지 (이모트만)
- 기믹 설명을 이모트(`/point`, `/no`, `/yes`)로만 해야 함. 파티 모집에서 "말 금지 파티"로 모으면 의외로 사람 모임.

### 🎲 블라인드 (공략 안 보고 처음 가기)
- **방법:** 새로 나온 극·영웅 토벌전에 공략 영상 안 보고 진입. 전멸할 때마다 다 같이 추리.
- 해외에서는 "Blind Prog"라고 해서 고정 공대 문화가 따로 있을 정도로 인기.

## 10. 주의사항
- **매칭으로 들어가지 말 것.** 모르는 사람이 섞이면 민폐가 되니까 **고정 파티 + 파티 모집**으로만 진행.
- 외부 툴(시점 변경 MOD, 플러그인)은 약관 위반이니 **게임 기본 기능만** 쓰기.
- 처음엔 **낮은 레벨 일반 콘텐츠**로 시작하고, 익숙해지면 극·영웅으로 올리기.
